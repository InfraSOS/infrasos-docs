# 365 Command

**In development.** Reporting and management for Microsoft 365.

A separate product rather than a module of AD Command: it authenticates to a different directory,
runs nowhere near a domain controller, and shares no deployment model with either AD Command or AD
Command Pro. Bundling them would mean one of the two carried assumptions that do not hold for the
other.

No date, and nothing else to say yet that would still be true when it ships.
