# 365 Command - screenshot shot-list

The 365 Command docs reference these screenshots. Capture each from
[command.infrasos.com](https://command.infrasos.com) and save it to
`docs/assets/screenshots/` with the **exact filename** below. The pages already point at these
paths, so each image appears as soon as the file is added - no further edits needed.

(This file lives at the repo root, outside `docs/`, so it is not published to the site.)

| Filename (into `docs/assets/screenshots/`) | Used on | What to capture |
| --- | --- | --- |
| `365-overview.png` | 365 Command home + site home | The Overview for a connected tenant: headline KPIs and the needs-attention list. |
| `365-tenants.png` | Connecting tenants | The Tenants page with a connected tenant, showing Enable Actions / Refresh. |
| `365-users.png` | Reporting | The Users report with a filter open and the column chooser or Export visible. |
| `365-secure-score.png` | Security | The Secure Score page: the score, its 30-day trend, and recommended actions. |
| `365-management-console.png` | Management actions | The Management console: KPIs, needs-attention, quick actions, bulk operations. |
| `365-offboard.png` | Management actions | The offboarding wizard mid-flow, showing the leaver checklist. |
| `365-intune.png` | Intune | The Intune page: managed devices and compliance (needs an Intune-licensed tenant). |
| `365-global-view.png` | MSP Global View + site home | The Global View: priority actions and the sortable tenant table across the fleet. |

## Tips

- Use a clean demo or test tenant, and avoid real PII (names, email addresses) in the frame, or blur
  it before saving. Directory data in a public screenshot is hard to take back.
- Landscape, roughly 1600-1900px wide, to match the AD Command screenshots already in
  `docs/assets/screenshots/`.
- PNG. Keep the browser chrome out of the frame where you can, so the shot is the product, not the
  browser.
